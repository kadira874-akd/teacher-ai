# Teacher Workflow

## Sebelum Mengajar

- Datang ke sekolah
- Melihat jadwal hari ini
- Menyiapkan perangkat ajar

## Saat Mengajar

- Memulai Learning Session
- Absensi
- Menyampaikan tujuan pembelajaran
- Menyampaikan materi
- Diskusi
- Latihan
- Penilaian
- Refleksi
- Menutup pembelajaran

## Setelah Mengajar

- Menulis jurnal
- Memberikan tugas
- Memeriksa tugas
- Memberikan nilai
- Melihat perkembangan siswa

## Akhir Semester

- Analisis perkembangan
- Menyusun rapor
- Berkomunikasi dengan orang tua
